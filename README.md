# 📱 Contact Management System Using Linked List

> A simple Python-based Contact Management System developed using a **Singly Linked List**.

---

## 🎯 Objective

To develop a simple and user-friendly **Contact Management System** using a Linked List in Python for storing and managing contact information.

---

## 📖 Introduction

The **Contact Management System** is a simple application that allows users to manage their contacts efficiently.

The project uses a **Singly Linked List**, where each node stores a contact's **name, phone number, and link to the next contact**.

This project demonstrates the practical use of Linked List operations in a real-world application.

---

## ✨ Features

| Feature | Description |
|---|---|
| ➕ Add Contact | Add a new contact |
| 📋 Display Contacts | View all saved contacts |
| 🔍 Search Contact | Search a contact by name |
| 🗑️ Delete Contact | Delete an existing contact |
| 🚪 Exit | Exit the application |

---

## 🧩 Data Structure Used

### Singly Linked List

Each node contains:

- 👤 Contact Name
- 📞 Phone Number
- 🔗 Link to the Next Node

**Structure:**

`[Name | Phone | Next] → [Name | Phone | Next] → NULL`

---

## 💻 Technology Used

- 🐍 **Python**
- 🔗 **Linked List**
- 🧱 **Object-Oriented Programming**

---

## ⚙️ Operations

### ➕ Add Contact
Adds a new contact to the linked list.

### 📋 Display Contacts
Displays all contacts stored in the linked list.

### 🔍 Search Contact
Searches for a contact using the contact name.

### 🗑️ Delete Contact
Removes a selected contact from the linked list.
